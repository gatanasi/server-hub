Phase 2 · 1–2 weekends

Platform core via Flux

Outcome: Flux owns the cluster. Cilium makes nodes Ready, a hello-world app answers on HTTPS at a LAN VIP with a valid wildcard cert, and deleting things by hand just makes Flux put them back.

Prereqs: Phase 1 cluster up. A GitHub personal access token (repo scope) for flux bootstrap. Your DNS provider API token for cert-manager DNS-01.

Steps

Gotchas

  • ▸ Copy Cilium's Talos capability lists from the current docs — they change between versions; don't hand-type from memory.
  • ▸ L2 announcements answer ARP on the node network — the VIPs must be in the same L2 segment as the LAN (they are, on vmbr0).
  • ▸ If HelmReleases sit in "not ready", check flux get all -A before digging into pods — ordering issues surface there.
Exit criteria: nodes Ready · podinfo on HTTPS with valid wildcard cert at the LAN VIP, reachable via VPN · delete-namespace test: Flux restores it · SOPS-encrypted secret decrypted in-cluster · everything above exists only as Git commits.
