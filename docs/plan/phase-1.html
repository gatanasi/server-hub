Phase 1 · 1–2 weekends

Provision: OpenTofu → Proxmox → Talos

Outcome: tofu apply turns bare Proxmox into a bootstrapped Talos cluster with a kubeconfig, and destroy → apply reproduces it in ~15 minutes. Node counts are variables.

Prereqs: Phase 0 complete (IP plan, CLIs, gitignore). Pin a current stable Talos version when you start and note it in tofu/variables.tf — check https://github.com/siderolabs/talos/releases.

Steps

Gotchas

  • ▸ Interface may not be eth0 — check the node console on first ISO boot and fix the patch.
  • ▸ After install, Talos boots from disk; leave the CDROM attached but disk-first in boot order, or detach it in the module.
  • ▸ If apply hangs on config-apply: the node is likely not in maintenance mode yet — give the ISO boot a minute.
  • ▸ Machine secrets live in tofu state — treat tofu/*.tfstate as secret material (it's gitignored; NAS copy should be on a protected share).
Exit criteria: destroy→apply reproduces the cluster in ~15 min · kubectl get nodes shows all nodes (NotReady, pre-CNI) · node counts scale by one-line diffs · etcd member drill done · schematic ID + Talos version pinned in vars.
